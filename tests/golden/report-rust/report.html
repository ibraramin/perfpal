PERF-RS-ALLOC-001Heap allocation inside loop (Rust)Detects Rust allocation sites — qualified constructors (`Box::new`/`Rc::new`/`Arc::new`/`Vec::new`/`String::new`/collection `new`/`with_capacity`), methods (`to_vec`/`to_owned`/`to_string`/`collect`/`with_capacity`), and the `vec!`/`format!` macros — at `in_loop_depth ≥ 1` AND `is_innermost`; surviving sites are aggregated into ONE finding per innermost enclosing loop (`alloc_count` plus sorted-unique short callee tokens capped at 8 with a `+N more` suffix). Literal-receiver `"…".to_string()`/`"…".to_owned()` (including raw/byte-string prefixes) are suppressed.
PERF-RS-ALLOC-002Deallocation inside loop (Rust)Detects a direct `drop` call inside a loop body (allocator churn pairing; escalated to hot when the same function also allocates in a loop).
PERF-RS-ALLOC-003Growable-buffer additive growth in loop (Rust)REFRAMED for Rust (no `realloc`): detects additive `reserve`/`reserve_exact` capacity growth inside a loop — the `realloc(p, n+k)` analogue; multiplicative capacity growth is the fix, not the finding.
PERF-RS-ARCH-001Module-graph fan-out / cycles (Rust)Detects module fan-out/fan-in, deep module chains, and cyclic module edges from resolved Rust module edges; unresolved internal `mod`/`use` edges are retained as graph data but intentionally emit no finding (their resolver cannot see crate-root or inline-module items).
PERF-RS-ARCH-002Hot-component aggregation (Rust)Ranks Rust component directories by aggregated metrics (complexity sum, alloc-site density, max loop depth) — the hottest component only.
PERF-RS-ARCH-003Cross-module call coupling (Rust)Detects cross-file/module call edges via name matching — LOW confidence, upgraded to MEDIUM when a semantic resolver fact resolves the definition.
PERF-RS-CALL-001Direct recursion (Rust)Detects a function body containing a direct call to its own name (presence-only; recursion depth is post-MVP).
PERF-RS-CALL-002High cyclomatic complexity (Rust)Detects branch-count complexity above threshold (default ≥ 15), reported per function.
PERF-RS-LOOP-001Deeply nested loops (Rust)Detects loop nesting depth ≥ 3 — O(n^k) candidate zones and primary input to hotspot maps.
PERF-RS-LOOP-002Expensive setup or I/O call inside loop (Rust)Detects Rust I/O/setup work nested in loops — `println!`/`print!`-family macros, reader/writer/socket methods (`read_to_string`/`write_all`/`flush`/`recv`/`send`), and `File`/`fs`/`Command`/`TcpStream`/`env` setup calls; lowered to warn when conditionally guarded. The message splits hoistable setup from intrinsic streaming transfer (recv/send/read_line — batching is the candidate); evidence carries io_kind.
PERF-RS-LOOP-003Character-wise processing in loop (Rust)REFRAMED for Rust (no char stdio): detects char/byte-at-a-time iterator or reader methods (`chars`/`bytes`/`char_indices`/`byte_indices`/`read_byte`) as the primary statement of a loop body.
PERF-RS-LOOP-004Variable-divisor division in innermost loop (Rust)Detects / or % with a non-literal divisor inside the innermost loop body (literal divisors skipped by design).
PERF-RS-LOOP-005Global variable written inside loop (Rust)Detects assignment to a Rust `static`/`const`-backed identifier inside a loop body (name-based scope classification, MEDIUM confidence).
PERF-RS-LOOP-006Indirect call in innermost loop (Rust)Detects indirect (function-pointer/trait-object) calls inside innermost loop bodies (LOW confidence; field-method/closure dispatch is classified direct and not seen).
PERF-RS-LOOP-007Linear membership scan nested in loop (Rust)Detects a comparison against a subscript indexed by an enclosing loop's induction variable — hand-rolled O(n²) membership scan.
PERF-RS-LOOP-008Member-chain dereference in innermost loop (Rust)Detects field/index access chains of depth ≥ 3 inside innermost loop bodies — pointer/lifetime-chasing cache-miss candidates.
PERF-RS-MEM-001size_of passed as an element count (Rust)REFRAMED for Rust: detects `Vec::with_capacity`/`String::with_capacity` receiving a `size_of`/`size_of_val` byte count where an element count is expected (over-reserves by the element size).
PERF-RS-MEM-002Block copy/clone in loop (Rust)REFRAMED for Rust (no explicit size argument): detects block-copy methods (`copy_from_slice`/`copy_nonoverlapping`/`extend_from_slice`) inside loops — warn in the innermost loop, info otherwise. (`clone`/`to_vec` were removed by the M1 Precision Gate: borrow-checker clones and `Copy` bit-copies are not block copies.)
PERF-RS-STR-002Length query recomputed in loop (Rust)Detects `len`/`is_empty`/`capacity` recomputed inside a loop where the receiver is not reassigned in the innermost enclosing loop.
PERF-RS-STR-003Unbounded unsafe memory operation (Rust)REFRAMED for Rust (memory-safe by default): detects the unsafe unbounded-op family (`copy_nonoverlapping`/`copy`/`from_raw_parts`/`from_utf8_unchecked`/`set_len`) anywhere — unchecked-length surfaces.
PERF-RS-TYPE-001Large struct passed by value (Rust)Detects a bare-named struct parameter whose LP64 estimate reaches the approximate-size floor (LOW confidence — no real type layout); one finding per function aggregating qualifying parameters.
PERF-RS-TYPE-002Struct field ordering (padding candidate, Rust)Detects struct definitions whose declared-order aligned layout wastes padding versus the packed member sum beyond the threshold — but default `repr(Rust)` may reorder fields automatically, so this is a lower-confidence candidate (check `#[repr(C)]`/FFI).
