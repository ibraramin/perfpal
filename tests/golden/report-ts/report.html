    Appendix A. Heuristic reference

    rule_idtitledescription
    PERF-JS-ALLOC-001Loop-invariant object/array literal inside loopDetects an object/array literal constructed inside a loop at depth ≥ 1 behind a mandatory loop-invariance/escape gate: silent when a referenced name is the nearest loop's induction variable or is mutated inside that loop, and silent when no enclosing loop contains the span. Mechanism: V8 young-generation allocation churn that escape analysis rarely elides; fix: hoist the invariant construction. Accepted FP class: a literal created once for another reason but mutated per iteration.
    PERF-JS-ALLOC-003Superlinear `concat`/spread/`slice` accumulation in loopDetects `concat`/`slice` called inside a loop on a non-empty receiver that the same loop reassigns (`acc = acc.concat(x)`), or an array literal with a spread that folds a loop-reassigned accumulator (`acc = [...acc, x]`) — the accumulator pattern. Each pass copies n elements, making the loop O(n²); fix: push into one array or concat/spread once after the loop. Accepted FP class: a deliberate immutable snapshot per iteration. Info.
    PERF-JS-ARCH-001Import cycleDetects cycles over RESOLVED relative-import edges, one finding per broken edge anchored at its earliest directive span. Mechanism: module-init ordering becomes observable and bundlers cannot tree-shake the cycle cleanly; fix: break the lowest-sorted edge into a shared leaf module. Accepted FP class: type-only import cycles (TypeScript erases them). Info.
    PERF-JS-ASYNC-001`await` inside a loopDetects an `await` at loop depth ≥ 1 inside an `async` function — awaiting each item sequentially serialises one microtask round-trip per iteration; fix: collect the promises and await `Promise.all(items.map(...))`. Accepted FP class: deliberately sequential work (rate limiting, ordering). Flagship, Warn.
    PERF-JS-ASYNC-002Synchronous blocking call inside `async` functionDetects a known synchronous Node API (`readFileSync`, `execSync`, sync `crypto`, …) called anywhere in an `async` function — the blocking call stalls the single event-loop thread for every concurrent task; fix: use the async equivalent (`fs/promises`, async `exec`/`spawn`). Async-function gate mandatory; accepted FP class: a CLI single-shot path. Flagship, Warn.
    PERF-JS-CALL-001Direct recursion without a visible base caseDetects a bare direct self-call (`receiver_root` absent) ONLY when no comparison in the same function has a span strictly before the recursive call — the guard-gated predicate for a missing visible base case. Mechanism: stack growth plus repeated frame-setup cost; fix: convert to a loop with an accumulator or add an explicit guard. Accepted FP class: a recursive tree walk with small depth. Info.
    PERF-JS-LOOP-001Nested loop depth ≥ 2Detects a loop nested at depth ≥ 2 (the JS floor is 2, not the C catalog's 3), at most one finding per function anchored at the earliest such loop. Mechanism: every extra level multiplies the iteration count, so the body runs superlinearly; fix: flatten the nesting, hoist invariant work, or add an early exit. Accepted FP class: matrix work where n² is inherent. Info.
    PERF-JS-LOOP-002Synchronous blocking I/O inside loopDetects a known synchronous Node API (`readFileSync`, `execSync`, `spawnSync`, sync `crypto`, …) inside a loop — one blocking syscall/serialization per iteration on the single event-loop thread; fix: batch, use the async API, or make one call outside the loop. Accepted FP class: a startup-only loop. Warn.
    PERF-JS-LOOP-007Linear membership scan inside loopDetects `indexOf`/`includes`/`find`/`findIndex`/`some`/`every`/`filter` called inside a loop with a non-empty receiver root, excluding canonical loops with a known trip count < 16 — a linear scan per iteration makes the loop O(n²); fix: build a `Set`/`Map` once and do a keyed lookup. Flagship, Warn.
    PERF-JS-STR-001String accumulation with `+=` or `x = x + …` inside loopDetects a string/template literal appended inside a loop in either form: `s += "…"` or `s = s + "…"` (the binary `+` must be the whole right-hand side), excluding canonical loops with a known trip count < 8. Mechanism: cons-string flattening at first use (MEDIUM; V8 ropes mitigate); fix: collect parts into an array and `join("")` once. Accepted FP class: a tiny bounded loop. Warn.
    PERF-JS-TYPE-001`delete` on an object propertyDetects `delete obj.prop`; the subscript form (`delete obj["k"]`) is EXCLUDED per the frozen disposition. Mechanism: a V8 hidden-class → dictionary-mode transition slows every later access; fix: set the property to `undefined` or rebuild the object. Accepted FP class: intentional cache eviction (rare). Info.
