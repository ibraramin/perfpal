Appendix A. Heuristic reference

rule_idtitledescription
PERF-C-ALLOC-001Heap allocation inside loopDetects malloc/calloc/realloc/aligned_alloc/strdup calls nested anywhere inside a loop body.
PERF-C-ALLOC-002`free()` inside loopDetects free() directly inside a loop body (paired with ALLOC-001 it indicates allocator churn).
PERF-C-ALLOC-003`realloc()` linear growth in loopDetects realloc(p, n+k) additive-growth shapes nested in loops — quadratic memmove behavior.
PERF-C-ARCH-002Hot-component aggregationRanks components by aggregated metrics (complexity sum, alloc-site density, max loop depth, finding density).
PERF-C-ARCH-003Cross-file call coupling (name-based)Detects cross-file call edges via name matching — LOW confidence until a semantic resolver tier exists.
PERF-C-CALL-002High cyclomatic complexityDetects branch-count complexity above threshold (default ≥ 15), reported per function.
PERF-C-LOOP-001Deep loop nesting (≥3)Detects loop nesting depth ≥ 3 — O(n^k) candidate zones and primary input to hotspot maps.
PERF-C-LOOP-002Expensive setup / I/O call inside loopDetects printf-family, file-I/O, getenv, system, and regex-compilation calls nested in loops. The message splits hoistable setup (hoisting or batching is the candidate) from intrinsic streaming I/O (read/write — batching into block transfers is the candidate); evidence carries io_kind. Calls in do-while(0) wrapper bodies stay silent.
PERF-C-LOOP-004Integer div/mod with variable divisor in innermost loopDetects / or % with a non-literal divisor inside the innermost loop body (literal divisors skipped by design).
PERF-C-MEM-001sizeof-misuse shapes in allocation argsDetects malloc(x * sizeof(ptr)) and sizeof misplacement shapes in allocation arguments — wrong-size allocations.
PERF-C-STR-001String accumulation in loop (`strcat` family)Detects strcat/strncat with a destination reused across loop iterations (O(n²) rescan).
PERF-C-STR-003Unbounded copy family (`strcpy`/`sprintf`/`gets`)Detects unbounded copy calls (strcpy, strcat, sprintf, gets, scanf %s) — unbounded-latency hotspots.
PERF-C-TYPE-001Large struct passed by valueDetects struct-typed by-value parameters whose TU-defined struct reaches the approximate-size floor (LOW confidence — no real type layout at MVP).
