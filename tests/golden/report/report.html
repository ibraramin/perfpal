PERF-C-CALL-002High cyclomatic complexityDetects branch-count complexity above threshold (default ≥ 15), reported per function.
PERF-C-LOOP-001Deep loop nesting (≥3)Detects loop nesting depth ≥ 3 — O(n^k) candidate zones and primary input to hotspot maps.
PERF-C-LOOP-002Expensive setup / I/O call inside loopDetects printf-family, file-I/O, getenv, system, and regex-compilation calls nested in loops. The message splits hoistable setup (hoisting or batching is the candidate) from intrinsic streaming I/O (read/write — batching into block transfers is the candidate); evidence carries io_kind. Calls in do-while(0) wrapper bodies stay silent.

PERF-C-STR-001String accumulation in loop (`strcat` family)Detects strcat/strncat with a destination reused across loop iterations (O(n²) rescan).
PERF-C-STR-003Unbounded copy family (`strcpy`/`sprintf`/`gets`)Detects unbounded copy calls (strcpy, strcat, sprintf, gets, scanf %s) — unbounded-latency hotspots.
