## 3. Timed-read protocol

- Fresh-context participant; **rendered page only** (`document.body.innerText` + screenshots),
  1440×900, default browser settings (**animation enabled**, no reduced-motion override).

  charts; no Explorer, per-file drills, external links, page source, repo docs or prior tool knowledge.

  yes/no in their own words, and list blockers.

  hashes/sizes in `a2/lanes/MANIFEST.txt`.
