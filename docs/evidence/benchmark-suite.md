# M2 benchmark suite — scale-ladder evidence (plan `evidence-beta`)

> **Scope.** This is the **M2 benchmark suite (build + RUN)**: a
> deterministic in-code ground-truth (mutation) catalog, a **scale ladder**
> (`small` / `medium` / `large` corpora), and a **two-run byte-determinism
> proof**. It raises the M1 lightweight per-rule KPI
> (`tests/fixtures/precision/`, `docs/evidence/precision-baseline.md`) **to
> scale**, and it is a **hard precondition for the publish gate**
> (ADR-0005). The metric is measured precision/recall against planted ground
> truth, not designed on paper.
>
> **Reproduce:** `cargo test --locked --test benchmark -- --nocapture`
> (add `--features semantic-clang` for the resolver build). The suite is
> always-on and hermetic: every generated corpus and report lives in a fresh
> tempdir and is removed on completion.
>
> **Repro packet (ADR-0005).** One command reproduces this record:
> `cargo test --locked --test benchmark -- --nocapture`. The scale ladder is
> fully materializable from committed source — no generated corpus is
> committed, so there are no stale on-disk artifacts to drift.

---

## 1. What M2 is

M2 = **benchmark suite (build + RUN)**. It has three parts:

1. **Ground-truth (mutation) fixtures** — planted true positives with computed
   anchors, plus silent controls.
2. **A scale ladder** — `small` / `medium` / `large` corpora that replicate the
   planted mutations at increasing file counts.
3. **A determinism proof** — byte-stable artifacts across two runs.

The corpus is generated **in code** by a deterministic mutation catalog:
`tests/benchmark/corpus.rs` (catalog), `tests/benchmark/mod.rs` (harness),
`tests/benchmark.rs` (entry). No generated corpus is committed — this keeps
every rung deterministic and materializable into a fresh tempdir.

The harness runs the **REAL** pipeline via `perfpal::cli::run_with`
(scan → analyze → aggregator → writer), exactly as a user run would.

---

## 2. Corpus, ground truth, and the generator contract

**Ground truth = planted mutations with computed anchors.** Every template
marks its anchor line with a stable comment token (`/* TP PERF-C-… */`,
`// TP PERF-RS-…`); `anchor_line` scans the exact generated bytes for that
token and records its 1-based line. Labels are therefore computed from the
bytes that get written — they **cannot drift** from a hand-maintained line
number. The full labels/scoring contract lives in
`tests/fixtures/benchmark/README.md`.

**Ratchet baseline:** `tests/fixtures/benchmark/baseline.json` — the intended
**1.0/1.0** target, and it must **NEVER** be lowered to make a test pass.

**Coverage.**

- The `small` rung plants a true positive and an explicit `Silent` control for
  **ALL 67 active rules** (23 C + 22 Python + 22 Rust), plus the retired
  `PERF-RS-STR-001` always-silent control. The harness asserts the set of rules
  carrying a `Fire` label **equals** the 67 active rule ids (derived from the
  product's public rule-id constants, so a deleted corpus unit fails the suite),
  that `Silent` coverage is exactly those 67 plus `PERF-RS-STR-001`, and that
  every `baseline.json` key is planted by at least one rung (no stale entries).
  The nine existential M1 gate constructs are lifted **verbatim** from the
  committed M1 corpus (including the six Python KPI fixtures, plan
  `python-backend` W4), retaining every M1 fire anchor.
- `medium` / `large` replicate the **NINE** existential M1 gate rules
  (`ALLOC-001`, `ARCH-003`, `MEM-002`, `LOOP-008`, `STR-001` × C+Rust) with
  **per-replica unique names** (`_k` suffix) so replicas can never trip the
  cross-file name-uniqueness gate (ARCH-003), create a false cross-file call
  edge, or form an accidental include/component hub.

The `medium` / `large` rungs are sized by whole replicas of
`FILES_PER_UNIT = 22` (12 C + 10 Rust files), rounded up.

## 3. Scoring

For each scoped rule:

- **TP** = the set intersection of `fire` labels and findings on
  `(rule_id, path, span.start_line)` (a duplicate finding at a fire coordinate
  is not double-counted);
- **FN** = a `fire` label with no matching finding;
- **FP** = **ANY** finding of a scoped rule with no matching `fire` label —
  this subsumes every silent control;
- `precision = TP/(TP+FP)`, `recall = TP/(TP+FN)` (1.0 on an empty
  denominator).

A scored rule with **no** `Fire` label would measure 0/0/0 and ratchet vacuously
to 1.0/1.0, so the harness asserts every scored rule carries a `Fire` label —
the only exemption is the retired `PERF-RS-STR-001` (mirrors the M1 guard in
`tests/precision_kpi.rs`). Silent controls are validated too: every `Silent`
rule must be inside the scored set.

The ratchet is **per rung**, scoped to the rules that rung actually plants
(`small` ratchets all 67 active rules + the retired control; `medium`/`large`
ratchet only the nine gate rules they replicate). Measured precision/recall
**MUST** be `>=` baseline; a shortfall is a **real analyzer gap or a corpus
bug** — never a reason to lower the baseline.

**Parse health.** Every generated corpus asserts `parse_health` all `ok` with
zero partial/failed (`files[].parse_health.status` + `parse_health_summary`).
The committed real-code rung asserts `failed == 0` **and** `partial == 0`
(these corpora are committed-clean; partial is not tolerated).

## 5. Determinism proof

Each rung — every labeled rung **and** the committed real-code mixed rung —
runs **twice** into separate output dirs (`out1` / `out2`), and the artifacts
must be byte-identical after a **strict, provenance-only** mask. The benchmark
uses its own masks (`tests/benchmark/mod.rs`), deliberately NOT the shared
`tests/common` golden masks: `mask_golden_metrics` serde-round-trips (which
canonicalizes key order) and `mask_golden_report` deletes the whole §4
`Cross-file call coupling` block — both too weak for a byte-stability claim.

Field-by-field, the mask is exactly:

- `metrics.json` — ONLY `scan.started_at`, `scan.duration_ms` and
  `scan.root_path` are neutralized, by **textual substitution of the JSON value
  token** (no re-serialization): the producer's exact key order, indentation and
  every other byte survive. Nothing else is masked.
- `report.md` — ONLY the provenance surfaces (`mask_report_provenance`: the
  header `started <RFC3339>` instant and `duration <n> ms`) plus every literal
  and Markdown-escaped occurrence of the absolute scan root. The §4 findings
  block is **not** deleted; the same build over identical bytes must render it
  byte-identically.
- `charts/*.svg` and the bundled schema — compared **byte-exact** (unchanged).

If the strict comparison ever surfaces a legitimate run-to-run difference, the
mask is extended for that specific field and the extension is disclosed here —
it is never silently re-widened.

The comparison is non-vacuous: it asserts the canonical v1 artifact set is
present (`metrics.json`, `report.md`, `SCHEMA_ARTIFACT_NAME` — derived from
`perfpal::schema`, so an additive schema bump does not break it — and all three
`charts/` SVGs). On a mismatch the two normalized copies are written into a
`TempTree`-owned dir whose path is named in the panic, and which is cleaned up
on unwind.

**Determinism verdict: PASS.**

## 7. Limitations / honesty

Stated plainly, not spun:

- The ladder corpora are **synthetic/generated** (deterministic), **not
  external real-world repos**. Real-repo credibility is **M4's** job. The
  `real-code` rung is internal committed code (unlabeled).
- **IR-only semantic sub-cases are NOT plantable from plain source** and are
  covered by the `tests/fixtures/ir/` fixtures + the `semantic-clang` build,
  not by the plain-source benchmark: proven-`fclose` ALLOC-002, resolved-format
  STR-003, resolved-edge ARCH-003; and the ARCH-001 deep-chain (≥8) / hub
  fan-out (≥12) sub-cases. The plain-source benchmark plants the required
  ARCH-001 **cycle** true positive instead.
- **Wall-clock is NOT gated** (recorded informationally only); the harness
  gates P/R + parse health + determinism.
- **Carried from M1:** semantic-tier USR ambiguity for duplicate external C
  definitions remains open — see `precision-baseline.md` §6.
