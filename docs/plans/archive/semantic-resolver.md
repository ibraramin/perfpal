## Idea
Realize ADR-0001's deferred semantic resolver tier as an additive libclang-based enrichment stage between scanner and analyzer (cli/mod.rs:181–184), retiring documented syntactic-tier FP/limit classes: ARCH-003 name-edge false positives (same-name static functions across TUs, duplicate names across vendored deps), ALLOC-002's fclose deferral (heap-backedness not syntactically decidable), STR-003's silent non-Literal format args, and — stretch — LOOP-004's constant-foldable-divisor FP class. Integration facts (@librarian-verified): clang-sys 1.9.1 (Apache-2.0) runtime mode = lazy dlopen via libloading; libclang C API is ABI-stable; licenses already in deny.toml allowlist; libclang parses non-compiling TUs partially (CXErrorCode + diagnostics + CXTranslationUnit_KeepGoing) fitting ParseHealth philosophy (enrich only verified, never delete). HARD CONSTRAINT: musl dlopen is impossible (static musl stubs dlopen to failure; dynamic musl can't load glibc libclang) — per founder decision, cargo feature `semantic-clang` (default OFF) gates the capability; darwin x2 + windows-msvc release builds pass the feature; NEW x86_64-unknown-linux-gnu (gnu) 6th release target added via cargo-zigbuild; musl x2 builds stay byte-identical (feature absent). Resolver rules: mirror resolve_includes post-backend pass pattern; NEVER change identity keys (path,name,span) or IR record shapes (modules.md §4.3); conservative tier upgrade — CallEvent/FunctionRecord resolver_tier raised to Semantic ONLY on unambiguous resolution (ambiguous same-name targets stay Syntactic → current LOW-confidence path); deterministic enrichment (sort by identity keys); resolver failures recorded via ParseHealth surfaces (additive optional = minor bump). Confidence upgrade path added centrally (apply_upgrade_hooks mirroring apply_downgrade_hooks); call_graph.edges[].confidence widened from const "LOW" to oneOf [LOW,MEDIUM,HIGH] as MINOR schema bump (additive widening; old reports still validate) with metrics-json-v1.md §5 amendment + bundled schema re-emission + golden regen. Parser-free testing per ADR-0001 guardrail 2: fixture stubs with resolver_tier:"semantic" + real-parse locks in a feature-gated CI job (libclang via apt). Distribution decision folded into modules.md §5.3 (no standalone ADR, language-fork precedent).
