## Idea
Fix the guarded-content scanner defect discovered while building the examples/ corpus. Root cause: src/scanner/backends/tree_sitter_c/mod.rs extract() Pass 1 (lines ~97-120) walks only DIRECT children of translation_unit (goto_first_child/goto_next_sibling), and Pass 2 (~122-137) does the same to find function_definition. tree-sitter-c nests everything inside preprocessor conditionals under preproc_ifdef/preproc_if/preproc_else nodes, so the everyday guarded-header shape is invisible: guarded #include (the ARCH-001 edge/cycle input), guarded #define (the macro recognizer that feeds macro_suspect downgrade hooks), guarded struct_specifier (TYPE-001/002 input), guarded globals (LOOP-005 scope classification), and guarded function_definition (all function-level rules). Proven by bisect: /var/tmp/bxA unguarded vs bxB guarded -> t.h include_counts.quoted 1 vs 0 and no graph edge; /var/tmp/g1 unguarded vs g2 guarded -> 1 vs 0 PERF-C-TYPE-002 findings. FIX (founder-approved breadth): replace the two direct-children walks with one recursive file-level walk that visits every node but STOPS descending at function_definition boundaries (so function-local declarations/structs are never mis-collected as file-level). Pass 1 matches preproc_include / preproc_def / preproc_function_def / struct_specifier / declaration anywhere in the file-level tree; Pass 2 collects function_definition the same way (founder approved covering guarded functions too). Then add regression tests (guarded include/define/struct/global/function + nested conditionals + a negative that function-local declarations stay invisible) and an end-to-end integration test in tests/guarded_content.rs mirroring the bisects (guarded include edge, guarded struct -> TYPE-002, a guarded include CYCLE -> ARCH-001 cycle, guarded global -> LOOP-005). Finally retire the corpus caveats: examples/cycle_a.h and examples/cycle_b.h now DO report the ARCH-001 cycle (Warn/HIGH, anchored at cycle_b.h) and examples/10_cross_file_and_arch.c caveat #1 is removed (caveat #2, HUB fan-out, stays). Re-measure the corpus totals (default + semantic-clang) and update every affected expected-findings list. Note: the handoff predicted +2 cycle findings; break_cycles drops exactly one lowest-sorted edge per 2-node cycle, so the measured delta is expected to be +1 — verify empirically and report the true number. Constraints: no behavior change for unguarded content; no new dependencies; keep the walk deterministic; dual review + full gates before commit.
