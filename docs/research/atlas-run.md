## 1. Vision

The Atlas map is spatial: it answers *where to look* (entry, HOTTEST, path, blast radius)
(`docs/NORTH-STAR.md:17-21`). It does not answer **order**: what starts first, what it reaches, where
the loops are, what is never reached, and where the story stops. Atlas Run adds that temporal reading
as a **story over the same static view model**:

> **Where might time go, in what order, and where does it stop?**

The story is presentation, not new analysis: it may reorder, pace, zoom and annotate existing fields,
but not add a metric, probability, duration, or unsupportable claim. Static analysis is approximate;
outputs are optimization candidates a profiler or human confirms (`docs/NORTH-STAR.md:30-32`;
`src/reporter/atlas.rs:14-16`).

| Track | Scope | Gate | Output |
|---|---|---|---|
| **D1** | Standalone static prototype that plays the inferred story; full interactive controls. | Track guardrails (`atlas-run.md:38-42`): no production edits, no target execution, no network, no schema/dep change. | `sim/` prototype + `docs/evidence/atlas-sim/` + this doc. |
| **D2** | Founder watches, iterates, and decides: companion or report. | Founder visual check, then a **new ADR + A12 amendment** if in-report. | Decision record. |
| **D3** | Spec/ADR for a real runtime trace + replay. No code. | Founder ratification of the ADR (post-beta). | Trace schema + ADR. |

## 2. What D1 is and is not

**Is:** a deterministic presentation of `AtlasView` (`src/reporter/atlas.rs:299-321`) plus, for
function detail, the same `metrics.json` that produced the render. Entry election, BFS depth, the
representative path, caps, coverage, edges and blast radius are already computed; the story sequences
them. **Is not:** a runtime trace, execution, sampler or profiler — it never runs the target, and there
is no measured clock, process, target read or network (`atlas-run.md:29`).

Explicit non-goals: no time units (cost is `static cost units (v2)`, v1 fallback —
`src/reporter/views.rs:28-42`); no measured iteration counts (only loop depth plus `literal` /
`partial` / `unknown` provenance and the largest literal trip — `src/schema/mod.rs:331-344`); no
branch prediction or call-frequency estimate; no claim that drawn edges are `resolved` (they are
structural, LOW name-based + MEDIUM semantic — `ADR-0009:69-76`); and no schema change, new dependency,
or production `src/reporter/` edit.

**Persistent honesty label.** D1 carries the track's label as
`STATIC, INFERRED · not a runtime trace · profile to confirm` (`sim/index.html:36`;
requirement `atlas-run.md:24`), visible at all times, not only in a footer. It is the companion of the
shipped report's `entry-flow map · static, profile to confirm`
(`src/reporter/atlas_render.rs:1214`). Label copy is fixed, not per-beat.

## 3. Story model

Seven beats, each grounded in a named field. The story is file-level: functions appear only as
highlights inside a file node.

| # | Beat | Evidence in the view model | What it shows | Honesty marker |
|---|---|---|---|---|
| 1 | **Boot at entry** | `entry.policy`, `.point` (path, name, line, cost, fan_in), `.confidence`, `.alternatives` (`atlas.rs:56-83`) | Which entry was elected and why (production main → script → lib-root) | "elected", not "started"; alternatives printed |
| 2 | **Representative path** | `path[]` (step, path, depth, cost) and `edges[].on_path` (`atlas.rs:162-169,202-209`) | The BFS route from entry to a leaf, step by step | `representative path (static, BFS-derived)` (`report.html:158`) |
| 3 | **Node / function highlights** | `nodes[].top_functions` (name, line, cost, rank, median, top_pct, fan_in) and `files[]` for every file (`atlas.rs:95-159`) | Which function in which file carries the static cost | Cost + anchor + unit; rank is static |
| 4 | **Loop / trip moments** | `max_loop_depth`, `unknown_trip_loops`, `trip_count_source`, `known_trip_value` (`schema/mod.rs:246,327-344`) | Where the estimate is incomplete, and literal trips | `unknown-trip ×N — estimate incomplete` / `known trip ×N — verify it actually runs` (`atlas_metrics.rs:404-425`) |
| 5 | **Branch not taken** | `entry.alternatives`; `unreachable_production` / `unreachable_nonproduction`; back edges; aggregates (`atlas.rs:68-74,167,171-189,310-311`) | The road visible but not on the path: other entries, unreached files, reverse edges | "not on this representative path", never "skipped at runtime" |
| 6 | **Hottest** | `hottest`, `hottest_node`, per-node `finding` (`atlas.rs:85-92,133,303-304`) | The single cost-ranked file and its dominant finding | Rank is by static cost, not elapsed time |
| 7 | **Stop / summary** | `state` flags, `caps`, `coverage`, `reachability`, `edge_mix`, `totals` (`atlas.rs:232-297`) | Why the story ends here and what was omitted | Counts with denominators; caps printed |

Beat 5 is the one most likely to be misread. The static model cannot say which arm of a branch runs;
the honest reading is **omission** — other eligible entries, structurally unreached files and reverse
edges are context so the path does not look like the whole program. "Branch not taken" is narrative
shorthand, not a prediction.

**Scan states.** `atlas-layout` §5 defines eight states (`atlas-layout.md:134-146`); the story keeps
the same shape and changes content:

| State | Story behaviour |
|---|---|
| **Application** (production main/script) | Full seven beats. |
| **Library / no forward path** | Boot at `library root (no production main)`; state `no forward path`; callers appear as reverse context; stop after blast radius. |
| **No entry** | A named `NO ENTRY` stub, no fake node, no fake boot. |
| **Empty / no functions** | Named stub `no source functions recorded`; no invented beats. |
| **All-test / test-dominated** | Hatching and counted shares are visible before any hot beat; production-first wording throughout. |
| **Capped** | The product draws aggregated boxes + an `N of M` chip; D1 demonstrates the stop copy with a labelled stub (no real capped scan was available). |
| **Partial parse** | `partial` badge on affected files; the story lowers precision there instead of omitting. |
| **Single-file** | One node, no edges; the path collapses to one step; blast-radius stub. |

**Controls and pacing.** Transport: play/pause, step back/forward, scrub, speed (0.5×/1×/2×/4×), reset,
node select and a case selector (`sim/index.html:19-32`). Select opens an inspector — path, role, cost +
anchor, top functions, finding (`sim/index.html:96-102`) — without leaving the map; `AUDIT.md:49-57`
records that removing this layer was a regression, and it is **detail, not a metric panel**
(`ADR-0009:51-54`). D1 pacing is presenter-controlled; the report's fixed CSS/SMIL timeline (0-1.2s→5.4s+,
pause only — `atlas-layout.md:158-169`) is not its template.

## 4. Honesty contract

Every beat states its inference class. The prototype may not promote an inference to a fact through
copy, motion, or emphasis.

| Beat | Inference class | Provenance shown | Must never be rendered as |
|---|---|---|---|
| Boot | Entry election by policy | `ENTRY … confidence … alternatives` | "execution started", "entry point called" |
| Path | BFS over structural edges | `representative path (static, BFS-derived)` | "the executed route", "call stack" |
| Node | Static cost rank | `static cost units (v2)` + `× median` + `top P%` | ms, µs, "measured", "spent" |
| Loop | Static loop count + trip provenance | `unknown-trip ×N — estimate incomplete`; `known trip ×N — verify it actually runs` | "runs N times", "iterations" |
| Branch | Structural omission | `2 alternatives`, `unreached`, reverse edge | "taken", "skipped", "% of calls" |
| Hottest | Cost rank | `HOTTEST: <file> · <cost> · <anchor>` | "slowest", "the bottleneck" |
| Stop | Caps + state flags | `N of M reachable files shown · N aggregated` | "program exited" |

**Unknown trips.** A loop with no literal trip contributes `1 × (1 + depth)` to `function_cost_v2` and
increments `unknown_trip_loops` (`schema/mod.rs:318-320`): a **floor**, not a guess that the loop runs
once. In the reference scan every loop-bearing function with provenance carries
`trip_count_source: "unknown"` (no `literal`/`partial` occurs in the hyperfine `metrics.json`), so loop
beats show the incomplete-estimate badge, not a trip number. `known_trip_value` is the largest clamped
literal used by the cost model (`schema/mod.rs:340-344`), and its label already says "verify it
actually runs" (`atlas_metrics.rs:409-412`); it may not be animated as if observed.

**Vocabulary.** The renderer rewrites runtime-flavoured rule text (`runtime`, `hot path`, `latency`,
`throughput`, `speedup`, `ms`, `µs`) into static wording (`src/reporter/atlas_brief.rs:1063-1089`). The
prototype reuses those rules and also forbids `measured`, `executed`, `observed`, `actual`, `real
time`, `% of runtime`, and unqualified `resolved` / `reachable` (`ADR-0009:73`). "Bottleneck" is a
question for a profiler, not a finding (`docs/NORTH-STAR.md:30-32`). **Cost scale:** v2 and v1 are not
interchangeable; each row carries its unit (`views.rs:28-42`) and the story never ranks across scales.

## 5. D2 — founder review and the companion/in-report decision

**Protocol.** (1) The founder watches at 1440×900 with motion on, then checks reduced-motion and print
final frames. (2) Both reference repos: hyperfine (application) and cJSON (test-dominated, partial parse). (3) Ask
the map's A2 question after the story: can the founder name the entry, the HOTTEST file and one
`path:line` action in under ten minutes (`atlas-layout.md:191-192`)? (4) Judge composition separately
from comprehension, side by side with the approved G baseline — V8 showed a comprehension-only gate can
pass a page the founder rejects (`AUDIT.md:119-125,150-165`). (5) Record: iterate, companion, or
graduate.

**What to watch / iterate.** Measurement implication; facts hidden mid-beat; top function reachable
without leaving the map; path vs back-edge legibility; every §5 state producing one action. Iterate
beat order/dwell, file-vs-function granularity, control set, labels, detail layer, state handling,
fold fit (`AUDIT.md:25-35`), palette/type (`AUDIT.md:36-47`), and path contrast (`AUDIT.md:84-90`).

**Companion vs in-report.** The static report stays zero-new-JS: A12 allows exactly one fixed
`REPORT_SCRIPT` and zero `<script>`/handlers in the canvas, SVG and animation artifacts
(`atlas-layout.md:198-201`; `ADR-0010:25-33,51-54`). It is fixed source that reads `data-*`, with no
network (`src/reporter/mod.rs:1705-1714`).

| Criterion | Companion (`sim/`) | In-report |
|---|---|---|
| Needs JS for play/step/scrub/select | Allowed; it is a separate file | **Blocked** by A12 |
| Expressible as CSS/SMIL over the static SVG | Not required | Required |
| Deterministic timeline from the view model | Nice-to-have | Required; double render byte-identical |
| Complete final frame, nothing only mid-story | Required | Required (`ADR-0010:34-38`) |
| Pause + reduced motion + print | Expected | Required |
| New schema field or dependency | Not allowed | Not allowed |
| Gate | Track guardrails only | New ADR + A12 amendment, then A1/A2/A4/A9/A10/A12 |

**Graduation is blocked** by any `<script>` or handler in the canvas/SVG/animation artifacts; any
network reference; a random or wall-clock timeline; mid-animation-only information; an incomplete final
frame; a schema change; or visual drift from G. It requires a **new ADR plus an A12 amendment**; the
single fixed `REPORT_SCRIPT` is unchanged and not repurposed as the story driver.

## 6. Appendix — D3 runtime trace / replay (proposal only; not a D1 deliverable)

> **Every item in §6 is proposed.** Nothing here is ratified, scoped, or implemented. No mechanism is
> chosen; the ADR must choose. Post-beta (`atlas-run.md:36`).

**6.1 Trace schema (proposed).** One event stream plus a header; times are integers in a declared unit,
and every record carries `clock_domain` and `tid`.

| Record | Required fields | Notes |
|---|---|---|
| call / return | `t`, `return_t`, `depth`, `caller_id`, `callee_id` | ids resolve to the static function id |
| loop | `loop_id`, `function_id`, `iteration`, `enter_t`, `exit_t` | measured counterpart of `trip_count_source` |
| allocation | `t`, `size`, `allocator`, `callsite` | size distribution, not just count |
| IO / syscall | `t`, `name`, `fd`, `bytes`, `blocked_ns` | kernel-side only where permitted |
| lock / contention | `t`, `lock_id`, `wait_ns`, `hold_ns`, `contended` | attribution is approximate |
| thread | `tid`, `parent_tid`, `start_t`, `stop_t`, `state` | required for concurrency claims |
| stack sample | `t`, `tid`, `frames[]`, `sample_rate_hz` | sampling mode only |
| source span | `path`, `start_line`, `end_line`, `static_id` | joins to `AtlasView` and `metrics.json` |

Header: `sampling {mode: event|sample|hybrid, rate_hz, dropped_events, loss_reason}`,
`volume {events, bytes, duration_ns}`, `clock {domain, resolution_ns, source}`, and a trace-format
version. A trace without dropped-event accounting is not replayable and must not be accepted.

**6.2 Correlation (proposed).** The join key is `path#name#start_line:start_col`
(`schema/mod.rs:238`); the display key is `path:line`. Every measured frame resolves to a static id, to
`unmatched`, or to `ambiguous`; unmatched frames are retained, counted and never dropped, and
correlation confidence is recorded per frame.

**6.3 Instrumentation options (proposed, tradeoffs unverified here).**

| Facility | Platform | Mode | Main tradeoff |
|---|---|---|---|
| eBPF / perf / ftrace | Linux | attach or launch | low app change; kernel privileges and symbol availability |
| ETW | Windows | attach or launch | kernel sessions need elevation |
| DTrace | macOS / BSD | attach or launch | SIP and entitlement limits on macOS |
| Python `sys.settrace` | CPython | launch | per-call overhead is high; pure-Python only |
| Node inspector | Node | attach or launch | JS only; sampling CPU profile |
| LLVM XRay | compiled C/C++/Rust | compile-time | needs a rebuild; function granularity |

**6.4 Sandbox, security, permissions (proposed).** Explicit per-run consent showing what will be
traced; pid/command and path allowlists; duration and volume caps; no network from the tracer and no
telemetry; argv/env/string/path redaction with review before export; prefer user-space/sampling, and if
kernel features are required, prompt, explain and drop privilege after attach. Failure modes are loud
(no permission, no symbols, unsupported platform, overhead breach, truncated trace); the tool never
silently falls back to the inferred story and presents it as measured.

**6.5 Languages and states (proposed).** Scanners are C, Rust and Python (`schema/mod.rs:185`); JS/TS
tracing waits on a JS backend. A trace needs a runnable target, so `no entry`, `empty` and some library
scans have nothing to measure; a supplied harness is allowed only if recorded as environment. Static
caps/partial-parse do not constrain a trace.

**6.6 Privacy and reproducibility (proposed).** Record once, replay the recording: replay reads the
stored stream, not a clock, filesystem or network. Capture binary sha256, cmdline, env allowlist, cwd,
kernel, CPU, governor, load, cgroup, and tool/format version. Do **not** promise identical re-runs —
schedules, ASLR and IO make that false; the guarantee is byte-stable **replay of the recording**.

**6.7 Replay and divergence (proposed).** Scrub measured time; breakpoints on function, line, loop
iteration, allocation size and lock wait. Divergence between static estimate and measured trace is a
first-class output: per function and loop, estimate vs measured with units and denominators, plus
unmatched marks. It is also calibration evidence for a model with no runtime ground truth.

**6.8 Decisions the ADR must make (proposed).** Facility per platform and one schema or several;
launch vs attach default and consent UX; sampling vs full events and the default rate; clock domain and
correlation rules; symbol resolution and unmatched policy; overhead budget and abort threshold;
redaction defaults; exact replay-determinism wording; divergence metric definition; storage
format/versioning under no-copyleft; and how measured time coexists with the Atlas "one measured
encoding" contract (`ADR-0009:77-79`) without becoming a second, competing encoding.

## 7. Evidence and reproducibility

- **Prototype:** `sim/index.html`, `sim.css`, `sim.js`, `data-*.json`, `from-layout.py`, `verify.py`,
  `make-source.sh`. The page is standalone: no build step, no network, no dependencies.
- **Serve:** `python3 -m http.server 8768 --directory sim` (`docs/tracks/atlas-run.md:25`).
- **Source renders:** `bash sim/make-source.sh` builds **this worktree** and scans the two fixture
  repos into `sim/source/out-{hyperfine,cjson}/` (gitignored). The shared
  `perfpal-test/out-atlas-v2-*` directories are deliberately not used: during D1 they were
  overwritten by a newer build from another worktree whose layout is an 868px canvas plus a right
  rail, not the approved step-10 full-bleed canvas. The build fails closed unless the stage is
  1400×718 (the report's `viewBox` and the core artifact's `canvas` must both agree).
- **Data provenance (S1, 2026-10-24):** Perfpal's own artifacts only. `atlas-layout.json` (`--story`)
  supplies geometry, badges, masthead/strip text, state flags, stages and KV1 actions; `metrics.json`
  supplies the drawn-file findings. `sim/from-layout.py` refuses a layout whose drawn-findings count
  disagrees with `findings_included`, embeds the layout SHA-256, and **no HTML is read**.
- **Counts (verified):** hyperfine — 53 files, 348 findings, 19 nodes / 49 edges / 5 hulls /
  6 columns / 3-step path. cJSON — 101 files, 837 findings, 7 / 5 / 2 / 3 / 2-step path.
- **Determinism:** `from-layout.py` twice produces identical sha256 for all six data files (including the index)
  (`docs/evidence/atlas-sim/NOTES.md`).
- **Gate:** `verify.py` asserts the honesty label, no rendered time units, all six transport
  controls, node select + Escape, final-frame completeness, 1440×900 fold fit, 1280×800 no
  horizontal scroll, reduced motion on the final frame, zero non-local requests, and unchanged data
  hashes.
- **Gate result (verified):** 101/101 checks on 2026-10-24 (`docs/evidence/atlas-sim/checks.json`);
  13/8 beats, 19/19 and 7/7 nodes, `#canvas-footer` bottom 894 ≤ 900, reduced motion at the final
  beat, zero non-local requests.
- **Vision:** `docs/evidence/atlas-sim/VISION.md`; eleven frames in `docs/evidence/atlas-sim/`.
- **Transcript:** `docs/evidence/atlas-sim/GATE.txt` records the source build/scan, two extraction runs
  with identical hashes, the Playwright gate (101/101, exit 0), and the untouched production tree.

## 8. Risks

| Risk | Impact | Mitigation |
|---|---|---|
| Static story read as measurement, "playable" implies execution | High — the core honesty claim | Fixed label, no time units, per-beat provenance, profiler framing, D2 question; copy says "inferred" |
| Visual drift from the approved G system | High — already observed once (`AUDIT.md:3-6,36-47`) | G as visual baseline, side-by-side founder check, composition gate |
| Extraction fragility when the renderer changes | Medium — silent wrong story | Pin `report_sha256`; prefer `metrics.json` + documented `data-*`; fail loudly on missing fields |
| Scope creep into the static report | Medium — breaks A12/determinism | Companion stays standalone; graduation needs ADR + A12 amendment |
| Runtime-trace feasibility/overhead | High for D3 | Platform matrix, sampling default, volume caps, explicit abort |
| Privilege and privacy exposure in tracing | High for D3 | Consent, local-only output, redaction, least privilege, no network |

**Not decided here:** graduation, the runtime facility, or measured time on the canvas — D2/D3 gates.
