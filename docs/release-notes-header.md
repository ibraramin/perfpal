> **Pre-release evaluation build — `0.5.1`.** Perfpal scans C, Rust, Python, JavaScript and
> TypeScript/TSX trees and writes a self-contained report whose main page is the **Atlas sim**: a
> self-contained, offline player for the inferred run. Provided for **noncommercial evaluation
> only** — not for commercial or production use. Governed by the bundled **EULA** (`EULA.md`),
> which supplements the PolyForm Strict `LICENSE`.
>
> **Binaries are UNSIGNED and the checksum manifest is UNSIGNED.** No Windows Authenticode or macOS
> notarization is applied, so Windows SmartScreen / macOS Gatekeeper may warn. Verify a download
> with `sha256sum -c <file>.sha256` or `sha256sum -c SHA256SUMS` (checksums only — there is no
> `SHA256SUMS.minisig` in this release).
>
> **No telemetry.** Perfpal makes no network calls and collects no data — see `PRIVACY.md`.
