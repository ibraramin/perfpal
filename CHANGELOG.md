### Fixed
- `ci.yml`: `dtolnay/rust-toolchain` requires an explicit `toolchain` input — the pinned action does NOT auto-read `rust-toolchain.toml` (verified in the action source); both uses now pass `toolchain: "1.92.0"`, mirroring `rust-toolchain.toml` and `release.yml`. - **Guarded-content scanner defect fixed** (plan `guarded-scan-fix`): the tree-sitter-c backend's file-level pass walked only the direct children of `translation_unit`, so `#include`, `#define`, `struct` and global declarations nested inside a preprocessor conditional — `#ifndef` include guards being the everyday header shape — were never collected. `extract()` now routes BOTH passes through one recursive `walk_file_level` helper that descends the whole file-level tree but STOPS at `function_definition` boundaries (function-local declarations/structs stay uncollected), so guarded file-level declarations AND guarded function definitions are collected. Fixed consequences: ARCH-001 include cycles now report — the planted `examples/cycle_a.h` ↔ `cycle_b.h` cycle fires as Warn/HIGH (anchored at the broken edge `cycle_b.h`, exactly ONE finding); the macro recognizer sees guarded wrapper `#define`s; TYPE-001/TYPE-002 see guarded structs (anonymous untagged structs are skipped so the wider reach can never emit an unattributable `struct ''`); LOOP-005 scope classification sees guarded globals. Bisect parity restored: `/var/tmp/bxA` vs `bxB` both report `t.h` `include_counts.quoted: 1` with a resolved edge; `/var/tmp/g1` vs `g2` both emit `PERF-C-TYPE-002`. Regression coverage: 10 backend unit locks (guarded include/define/struct/global/function, doubly-nested conditionals, the stop-boundary negative, the anonymous-struct skip, and the ratified named typedef/nested breadth) plus `tests/guarded_content.rs` end-to-end bisect-parity tests (include edge, guarded struct → TYPE-002, guarded cycle → ARCH-001, guarded global → LOOP-005). The `examples/` corpus caveat comments are retired and its counts move 82 → **83** (16 hot / 25 warn / 42 info) default and 84 → **85** `semantic-clang`; the ARCH-001 hub fan-out sub-case remains documented as deliberately non-firing. 252 tests green.
